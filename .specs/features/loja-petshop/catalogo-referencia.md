## Como usar esta referência

Usar nomes, categorias, fotos e valores das publicações para preparar a primeira versão do catálogo. Antes de publicar o site para clientes reais, a equipe precisa confirmar quais itens continuam disponíveis, seus preços atuais, as variantes e o direito de uso das imagens no site. Registrar a data da última conferência de cada produto ajuda a não tratar uma oferta antiga como preço atual. A equipe atualizará o catálogo do site; nenhuma sincronização automática com o Instagram foi definida.
